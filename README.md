AI Career Roadmap Generator

About

The AI Career Roadmap Generator is a web application built to help users plan their career development. It uses information about their education, skills, interests, experience, and career goals to generate a personalised learning roadmap.

The application was developed using Python, Streamlit, LangChain, and Google Gemini.

Features

Collects information about the user's education and experience
Takes input about current skills, interests, and career goals
Generates a career roadmap based on the provided information
Includes suggested skills, certifications, projects, and learning resources
Provides a six-month learning plan
Allows users to download the generated roadmap as a text file

Technologies

Python
Streamlit
LangChain
Google Gemini

API Key

A Google Gemini API key is required to generate career roadmaps. Enter the key in the application sidebar when prompted.
Keep API keys private and do not upload them to the repository.

Limitations

The generated roadmaps are based on AI responses and the information provided by the user. Recommendations should be reviewed independently before making career or educational decisions.
